# ⬇️ Video Downloader Automático

![Status](https://img.shields.io/badge/Status-Concluído-success)

## 💻 Sobre o Projeto
Script automatizado desenvolvido para ler uma lista de links fornecidos em um arquivo de texto (`.txt`) e realizar o download convertendo todos os vídeos diretamente para o formato `.mp4`.

## 🛠️ Tecnologias Utilizadas
* Python

## 🚀 Pré-requisitos e Como Executar

**Pré-requisito (Windows):** É necessário ter o `ffmpeg` instalado no sistema. 
Abra o terminal e execute:
```bash
winget install ffmpeg

python main.py
